Detail Kegiatan

Pagi (05.00-12.00)

Kegiatan di pagi hari dimulai dari jam 5 pagi hingga 12 siang. Pada jam 5 pagi, biasanya saya bangun tidur atau bisa lebih cepat. Ketika bangun, saya Sholat terlebih dahulu sebelum melakukan hal lainnya. Setelah saya sholat saya terkadang bersantai terlebih dahulu sambil memainkan handphone. Setelah jam 6 pagi, saya menyiapkan diri untuk pergi berangkat kuliah seperti mandi dan makan, Setelah saya siap saya langsung jalan menuju kampus. Setelah sampai di kampus, tentunya saya belajar disana bersama mahasiswa lain.

Siang (12.00-18.00)

Kegiatan di siang hari dimulai dari jam 12 siang hingga jam 6 sore. Pada jam 12 siang, saya biasanya Sholat Dzuhur terlebih dahulu dan dilanjutkan dengan makan siang, setelah itu saya melanjutkan kegiatan belajar di kampus. Setelah selesai kuliah, saya biasanya pulang ke rumah dan sesampainya di rumah saya beristirahat sejenak sambil bermain handphone atau menonton youtube sampai sore hari dan tidak lupa juga mengerjakan Sholat Ashar.

Malam (18.00-24.00)

Kegiatan di malam hari dimulai dari jam 6 sore hingga jam 12 malam. Pada jam 6 sore, saya biasanya Sholat Maghrib terlebih dahulu dan dilanjutkan dengan makan malam. Setelah itu, saya melanjutkan kegiatan belajar atau mengerjakan tugas kuliah. Menjelang tidur, saya biasanya menonton drama korea atau mendengarkan lagu. Sebelum tidur, saya juga menyempatkan diri untuk Sholat Isya. Setelah semua kegiatan selesai, saya tidur untuk mempersiapkan diri menghadapi hari esok.
